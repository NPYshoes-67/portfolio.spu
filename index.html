// 02_about-me

เกี่ยวกับผม

ทำความรู้จักตัวตน แนวคิด และเป้าหมายในสายงานของผมมากขึ้น

ผมชื่อ กฤษณชัย อุบลทิพย์ อายุ 23 ปี ปัจจุบันทำงานราชการ แต่ยังคงสนใจและพัฒนาทักษะด้าน Technology และ Programming อย่างต่อเนื่อง โดยใช้เวลาว่างในการเรียนรู้และทดลองพัฒนาโปรเจกต์ต่าง ๆ เพื่อเพิ่มประสบการณ์และนำความรู้ไปต่อยอดในการทำงาน

เป้าหมายของผมคือการพัฒนาตัวเองให้เติบโตในสาย Full Stack Developer มีความสามารถทั้งด้าน Frontend และ Backend และต่อยอดไปสู่ด้าน AI / Data ในอนาคต พร้อมนำความรู้และประสบการณ์ที่ได้มาสร้างซอฟต์แวร์ที่มีประโยชน์และใช้งานได้จริง
